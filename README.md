# head-hunter-hunter

Автоотклики на hh.ru. Локально, для себя.

## Быстрый старт

```bash
npm install
npx playwright install chromium     # если Chromium ещё не стоит
cp config.example.json config.json  # отредактировать под своё резюме
npm run doctor                      # проверка без обращения к hh
npm run login                       # откроется браузер — войти руками
npm run selectors:probe             # проверить селекторы на живом hh
```

## Что нужно знать

- **Автоотклики формально нарушают правила hh.ru.** Риск — временная или постоянная
  блокировка аккаунта. Подробности и оценка рисков — `.claude/RESEARCH.md` §5.3.
- `dryRun: true` по умолчанию: пайплайн проходит целиком, но ничего не отправляет.
- Лимиты по умолчанию (30/день, 5/час) намеренно сильно ниже потолка hh в 200 за
  скользящие 24 часа.
- Вход — только руками. Пароль в конфиге не хранится и не поддерживается.

## Состояние

Всё состояние — в `data/` (в git не попадает):

```
data/session/chromium-profile/  профиль браузера = сессия hh
data/hhh.sqlite                 вакансии, скоры, письма, история откликов
data/screenshots/               скриншоты ошибок и откликов
data/probe/                     отчёты разведки селекторов
```

Чтобы начать с нуля — удалить `data/`.
